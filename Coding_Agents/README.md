Prereqs (before the workshop, ~10 mins, Windows or Mac):
- Download the workshop zip from the AI Club Teams post and unzip it.
- Run the setup script for your computer: `setup.ps1` on Windows, `setup.sh` on Mac ([steps](setup/README.md)). It installs VS Code, Codex, Python, and git, skips what you already have, and signs you in with the workshop key. You don't need an OpenAI account.

Coding agents can read your project, edit files, run tests, and fix their own mistakes. On their own, they also guess what you meant, grade their own homework, and forget everything between chats.

In this workshop you'll set up a **software factory**: agent skills that each do one station of the work (intake, shape, build, audit, close), with you approving the important decisions and a shared **factory brain** (`BRAIN.md`) that makes the line smarter after every run. Then you'll have the factory build a Snake game with Codex, write your own audit station, and make the factory your own.
